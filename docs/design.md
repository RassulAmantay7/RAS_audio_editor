# Дизайн RAS audio editor

## Стиль (выбран пользователем — повторно не спрашивать)
**«Красивый / современный»**: аккуратные анимации, мягкие тени, скругления, тёмная тема по умолчанию. Тот же выбор, что у PDF-ридера этого пользователя; акцентный цвет — бирюзовый (#5EE0C2, как в иконке).

Дополнено ui-designer (T16). Код: `app/src/main/java/com/rassul/audioeditor/ui/**` и `MainActivity.kt`; без XML-разметки и `R.*`, без androidx.

## Принципы
- Тёмная тема по умолчанию (светлая палитра заведена в `Tokens.LIGHT`, включается `Ui.applyTheme(activity, dark = false)`; переключателя в настройках v1 нет).
- Один акцент — бирюзовый `#5EE0C2` (как в иконке); красный — только ошибки, удаление и перегрузка; янтарный — предупреждения.
- Инструментальный софт: числа и время — моноширинным шрифтом, единицы рядом со значением, ошибка — под полем (красная рамка 2dp + символ ⚠ + текст), смысл никогда не передаётся одним цветом.
- Мягкие поверхности: в тёмной теме карточки отделяет обводка 1dp (8 % белого), в светлой — тень; листы и плавающие панели — тень 16/8dp.
- Edge-to-edge: отступы из WindowInsets (панели, вырез, клавиатура). Системные «Убрать анимации» обнуляют длительности ValueAnimator.

## Макет
`docs/design/screens.png` — Главная (с панелью фоновой задачи), Извлечение (две дорожки, вторая без декодера — FR-9), Редактор (волна, выделение, перегрузка, поля, транспорт, действия), лист «Экспорт». ## Волна (`WaveformView`)
- Масштаб: от «весь файл» до 1 сэмпл = 8 px (`MIN_FPP = 0,125`). При масштабе ≥ 1 кадр/px рисуются мин/макс колонки (пирамида при ≥ 256 кадр/px, иначе сырые сэмплы); при < 1 — отдельные сэмплы (линия, при ≥ 4 px/сэмпл ещё и точки).
- Вертикальный диапазон ±1,15: линии ±1,0 (0 дБ) пунктиром, превышение видно над ними. Каналы — по полосе (до двух).
- Жесты: тап — перемотка; щипок — зум вокруг пальцев; перетаскивание — прокрутка с инерцией; долгое нажатие и движение — новое выделение; ручки (зона касания 28dp) тянутся, при перетаскивании у края — автопрокрутка. Кнопки «Приблизить/Отдалить/Весь файл» дублируют щипок.
- Без аллокаций в `onDraw`: краски, массивы, подписи шкалы времени (`CharArray`) создаются заранее; колонки пересчитываются только при изменении вида или версии данных.

## Контраст WCAG 2.1 AA
Порог: текст 4,5:1 (SC 1.4.3), элементы интерфейса и иконки 3:1 (SC 1.4.11). Расчёт — `docs/design/contrast.py` (читает `Tokens.kt`; относительная яркость L = 0,2126 R + 0,7152 G + 0,0722 B, канал c ≤ 0,03928 → c/12,92, иначе ((c+0,055)/1,055)^2,4; контраст (L1+0,05)/(L2+0,05)). Все пары проходят; перегрузка отличается от обычной волны не только цветом (полоса 3dp сверху колонок и подпись).

## Доступность
Кнопки-иконки имеют `contentDescription` и подсказку; переключатели и чипы — роль и состояние; заголовки помечены; ошибки и сообщения — live region. Поля времени дают точный ввод без жестов. У волны описание обновляется (длительность и выделение). Размеры текста — в sp.

## Для интеграции (T20)
- Переключение фейк/реальный — `MainActivity.USE_FAKE`. При `false` `Application` должна реализовать `ui.AppControllerHost { val appController: AppController }`.
- `WaveSource` (`ui/WaveSource.kt`): `EditorWaveSource(editor)` строит колонки по `editor.peaks` (уровень пирамиды — наибольший с блоком ≤ кадров/px) и `editor.readSamples` для масштаба < 256 кадр/px. Экран сам вызывает `touch()` на каждом `onStateChanged` — контроллер должен вызывать `onStateChanged` после пересчёта пирамиды. `readSamples` вызывается из потока UI на каждом кадре прокрутки: нужен быстрый (mmap/кэш) доступ, до ≈ 256·ширина кадров за вызов.
- `playheadFrame` опрашивается каждый кадр анимации; `EditorState.playing` включает анимацию курсора. `setSelection` вызывается один раз при отпускании ручки; во время перетаскивания UI показывает выделение сам.
- Экспорт, извлечение, быстрая обрезка вызываются через `MainActivity.beforeSave` (диалог про уведомления; запрос `POST_NOTIFICATIONS` один раз).
