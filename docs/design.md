# Дизайн RAS audio editor

## Стиль (выбран пользователем — повторно не спрашивать)
**«Красивый / современный»**: аккуратные анимации, мягкие тени, скругления, тёмная тема по умолчанию. Тот же выбор, что у PDF-ридера этого пользователя; акцентный цвет — бирюзовый (#5EE0C2, как в иконке).

Остальное (токены, экраны, состояния, контраст) дописывает ui-designer.
